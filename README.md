## 📌 Project Overview

**ExpenseIQ** is a smart personal expense tracker that helps users manage their finances by recording income and expenses, visualizing spending patterns, and setting category-wise budgets.

---

## ✨ Features

- ✅ Add income & expense transactions
- ✅ Dashboard with summary cards (Total Income, Expenses, Balance)
- ✅ Doughnut chart — spending by category
- ✅ Bar chart — weekly spending trend
- ✅ Transaction history with search & filter
- ✅ Category-wise budget manager with progress bars
- ✅ Delete individual transactions
- ✅ Data persists using localStorage (no backend needed)
- ✅ Fully responsive design (mobile + desktop)
- ✅ Toast notifications for user feedback
